有货未展示看板

用店面展示数据比对 non-discontinue 且有货的产品，找出有货但没展示的。
数据源：-
店铺有货率
-
有货未停产 / 全部未停产
展示覆盖率
-
已展示且有货 / 有货未停产
有货未展示（个）
-
有货未停产但未展示
有货未停产（个）
-
纳入分析的产品总量

各系列：有货 vs 有货未展示

有货未展示明细

产品编码 名称 系列 库存 价格
判定口径：有货未展示 = 库存 > 0 且未停产 (non-discontinue)，但产品编码不在店面展示清单中。
数据源支持：环境变量 INSTOCK_STOCK_CSV / INSTOCK_DISPLAY_CSV 或 INSTOCK_DATA_DIR 指向的 CSV；默认使用 sample_data/ 示例数据。 可直接用 Data-NZ 里的 SQL 导出结果作为 CSV，列名会自动模糊匹配。
